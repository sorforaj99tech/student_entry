# Student Entry Management System

A Django-based Student Entry Management System designed to manage student information efficiently and simplify administrative tasks through a structured web application.

## Features

- Add and manage student information
- View student records
- Update existing student details
- Delete student records
- Organized and user-friendly interface
- Database-driven data management
- Efficient student record handling

## Technologies Used

- Python
- Django
- HTML5
- CSS3
- JavaScript
- SQLite
- Bootstrap

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/sorforaj99tech/student_entry.git
   ```

2. Navigate to the project directory:

   ```bash
   cd student_entry
   ```

3. Create a virtual environment:

   ```bash
   python -m venv env
   ```

4. Activate the virtual environment:

   ```bash
   env\Scripts\activate
   ```

5. Install dependencies:

   ```bash
   pip install -r requirements.txt
